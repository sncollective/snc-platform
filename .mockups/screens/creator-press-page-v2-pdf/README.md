# Press PDF mockups — direction

**Default PDF (the v2-pdf feature):** matches the **locked web templates**
(`../creator-press-page/final-1.html`, `final-3.html`) — their aesthetic,
dense full content, print-usable Listen URLs. The reference is the locked
templates' `@media print` output (the `creator-press-page-v2-templates`
feature already ships the print CSS). Color scheme (Editorial Light / Dark /
Creator Brand Accent) is a creator-pickable option on this default template;
default scheme = Dark (web-matching).

**`zine-stretch/`** — the punkier zine/edgy/MTV/rock exploration (4 options),
parked as **reference for a future stretch goal** (a punkier PDF template +
possibly a punkier web template), deferred until aesthetics settle. Not the
default direction; not discarded.
