## Implementation discovery

`PressConfigPatchSchema = PressContentSchema.partial()` was not a safe patch
contract under the installed Zod 4. The defaults retained from
`PressContentSchema` were materialized while parsing a partial request; for
example, parsing `{ shortBio: "x" }` also produced `enabled: false` and empty
list fields. Unit 2 would therefore have disabled the page and cleared content
when patching an unrelated field. The operator authorized the default-free
resolution: `PressConfigPatchSchema` now declares every top-level field
explicitly optional, matching `JoinConfigPatchSchema`, while the complete
content schema retains its defaults.

## Implementation notes

- Execution capability: direct-read inline implementation; the bounded schema,
  contract, service, migration, and seed shared established join-page patterns.
- Review weight: standard (project default); independent review is not
  applicable to this child-story checkpoint.
- Files changed: `apps/api/src/db/schema/creator.schema.ts`,
  `apps/api/drizzle/migrations/0033_left_vance_astro.sql` and generated metadata,
  `packages/shared/src/press.ts`, `packages/shared/src/index.ts`,
  `apps/api/src/services/press.ts`, `apps/api/src/scripts/seed-press.ts`, and
  `apps/api/tests/services/press.test.ts`.
- Migration: `0033_left_vance_astro.sql` generated by Drizzle and applied to the
  local development database; generated SQL contains the primary key, creator
  profile foreign key, and cascade delete.
- Patch semantics: the complete content schema keeps defaults; the patch schema
  has explicit optional fields with no defaults. `upsertPressConfig` shallowly
  merges the parsed top-level patch over the current/default document, replacing
  present arrays or nested objects wholesale and preserving absent fields.
- Seed result: `seed-press.ts` created local-only `animalfuture` profile
  `375328a0-b99f-4961-80c5-65f8140cf35b`, then upserted the enabled Animal
  Future EPK. A second run reused the profile and upserted the same row. This
  profile is scaffolding for local verification only; the real Animal Future
  creator lives in prod/demo, where running the reusable seed against that
  existing creator is an operator deploy step because the agent has no prod
  access.
- Tests added: `apps/api/tests/services/press.test.ts` covers defaults on
  absence, shallow upsert round-trip, and the regression that parsing
  `{ shortBio: "Updated bio" }` must not inject complete-document defaults.
  No tests removed.
- Verification: shared typecheck passed; API typecheck passed; targeted press
  tests passed (3/3); full API unit suite passed (118 files, 1,902 tests);
  migration generation rerun reported no schema changes; service/DB probe
  verified defaults-on-absence, enabled seeded content, 14.5k standout label,
  SNCR-001, and zero photos.
- Simplification: reused the existing one-row config/upsert shape; no new
  abstraction or infrastructure added.
- Discrepancies from design: authorized explicit default-free patch schema in
  place of `.partial()`; the Drizzle schema imports the default directly from
  `packages/shared/src/press.ts` because loading the shared barrel through
  Drizzle's CommonJS generator also loads the Vitest-only storage contract.
